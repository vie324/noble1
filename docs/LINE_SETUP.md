# LINEリッチメニュー → カウンセリング 連携 設定ガイド

お客様が「LINE追加 → リッチメニュー → カウンセリング入力」と進み、その内容を
本システムの「受付」画面で確認しながらカルテ化できるようにするための設定です。

サロンボード（HPB）との自動連携の代わりとなる、手動運用の導線です。

---

## 全体の流れ

```
お客様: 来店/事前
  └ LINE公式アカウントを友だち追加
      └ リッチメニューの「カウンセリング」をタップ
          └ https://<本番URL>/f/new を開く（固定URL・1つでOK）
              └ 氏名・連絡先・お悩み・注意事項の確認を入力 → 送信

スタッフ: ダッシュボード
  └ 「今日」ボード上部に「新着カウンセリング ◯件」バナー
      └ 「受付」画面で内容を確認
          └ 「新規登録してカルテ作成」 or 「既存のお客様に紐付け」
              └ カルテが自動作成され、回答を見ながら記入・保存
```

ポイント: リッチメニューに設定するURLは **1つの固定URL** です。お客様ごとの個別
URLは不要です（お客様が氏名・連絡先を入力するため、スタッフ側で照合できます）。

---

## 1. 設定するURL

```
https://noble1.vercel.app/f/new
```

独自ドメインを設定している場合は、そのドメインの `/f/new` を指定してください。
（例: `https://noble-salon.com/f/new`）

> このURLは認証不要で、誰でもカウンセリングを送信できます。送信内容は顧客台帳には
> まだ紐付かず、スタッフが受付画面で確認・紐付けするまで「未紐付け」として保持されます。

---

## 2. LINE公式アカウントでリッチメニューを作成

1. パソコンで [LINE Official Account Manager](https://manager.line.biz/) にログイン
2. ノーブルの公式アカウントを選択
3. 左メニュー **「トークルーム管理」→「リッチメニュー」→「作成」**
4. **タイトル / 表示期間** を設定（タイトルは管理用、お客様には見えません）
5. **コンテンツ設定 → テンプレート** を選択
   - 「カウンセリング」ボタンを大きく置けるレイアウトがおすすめ
6. **背景画像を設定**
   - 各ボタンの位置に「カウンセリング」「ご予約」「メニュー」等の文字を入れた画像を用意
   - 推奨サイズ: 2500 × 1686 px（大）または 2500 × 843 px（小）
   - Canva 等で作成できます。画像が用意できない場合はテンプレートの色だけでも可
7. **アクション設定**
   - 「カウンセリング」のボタン枠を選択
   - **アクションタイプ：「リンク」**
   - **URL：** `https://noble1.vercel.app/f/new`
   - 表示テキスト（任意）：「カウンセリング」
8. **「保存」** → メニューを **「表示する」** に設定して完了

これで、友だち追加済みのお客様のトーク画面下部に常にメニューが表示され、
タップするとカウンセリングフォームが開きます。

---

## 3. 友だち追加の導線（来店時のご案内）

LINE Official Account Manager の **「友だちを増やす」→「友だち追加QRコード / URL」** から
QRコードを取得できます。受付・店内POP・名刺などに掲示してください。

---

## 4. 動作確認

1. スタッフのスマホでサロンのLINEを友だち追加
2. リッチメニューの「カウンセリング」をタップ → フォームが開くことを確認
3. テストで送信
4. ダッシュボードの「今日」ボードにバナーが出る → 「受付」で内容が見えることを確認
5. 「新規登録してカルテ作成」でカルテができることを確認
   （テストデータは後でお客様ページから削除できます）

## よくある質問

**Q. 店舗が複数ありますが、URLは分けますか？**
A. 分ける必要はありません。フォーム内でお客様が来店店舗を選択できます（1店舗運用なら選択は出ません）。

**Q. お客様のLINÉ名は自動で取れますか？**
A. このシンプル構成では取得しません。お客様がフォームに氏名を入力します。
LINEのプロフィールを自動取得したい場合は LIFF（LINE Developers）連携が必要で、別途開発になります。

**Q. 予約も取れますか？**
A. 現状はカウンセリングの受付のみです。予約自体はこれまで通りサロンボード等で行い、
朝に「今日」ボードで空カルテを作る運用と併用してください。

## 【案B】店舗ごとの Messaging API 連携（自動送信・友だち取得）

各店舗の LINE 公式アカウントと API で連携すると、システムから直接メッセージを
送信したり、友だち追加を自動で取り込んでお客様に紐付けできます。

### 設定（店舗ごとに1回）

1. [LINE Developers](https://developers.line.biz/) で、各店舗の公式アカウントに
   **Messaging API チャネル**を作成（または有効化）
2. **チャネルアクセストークン（長期）** と **チャネルシークレット** を取得
3. アプリの **経営 > LINE連携** を開き、店舗ごとに貼り付けて「保存」→「接続テスト」
4. 同じ画面に表示される **Webhook URL**（`https://<本番>/api/line/<店舗ID>`）を
   LINE Developers のチャネル設定に登録し、**Webhookの利用を「オン」** にする

### できること

- **友だちの自動取り込み**: お客様が店舗のLINEを友だち追加すると、`line_friends` に
  自動登録されます（表示名・アイコンも取得）。
- **顧客への紐付け**: 顧客ページの「LINE送信」欄に、主担当店舗の未紐付け友だちが
  候補表示されます。「このお客様に紐付け」で紐付けます。
- **店舗の公式アカウントから直接送信**: 紐付け済みのお客様へ、顧客ページから
  「カウンセリングを送る」「ビフォーアフターを送る」「自由メッセージ」を送信できます
  （その顧客の主担当店舗のトークンで送られます）。

### 注意

- トークン・シークレットは管理者のみが設定でき、画面には再表示されません
  （変更時のみ再入力）。
- 友だちのLINEユーザーIDは、お客様が友だち追加し何らかのアクション（追加・送信）を
  した後に取得されます。
